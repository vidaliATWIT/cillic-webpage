Metal Box

Buy on

Metal Box is a unique mutation of one of the earliest reverb algorithms, originally committed to paper in 1962. I built the prototype to serve my need for a claustrophobic, compressed reverb.

The plugin itself took shape after I found a glitch in my code that unravelled the resonant peaks of the feedback path into a glassy, ringing bloom. Instead of fixing it, I turned it into a variable parameter that lets you dial in the error within the algorithm.

Note on MacOS installers

Our MacOS installers are unsigned and as such will pop-up a message when you try to run them. Instructions for bypassing this below. Alternatively you can follow the video walkthrough here.

System Preferences override

  • Go to System Preferences/Settings > Security & Privacy > General
  • If you recently tried to open the file, you'll see a message about it being blocked
  • Click "Open Anyway" next to that message

Right-click method

  • Right-click (or Control+click) on the installer file
  • Select "Open" from the context menu
  • Click "Open" again in the security dialog that appears
